# 更新包 — v2.6.6-20261114

## 一、平台真实规则（由报错实测确认）

报错原文：

```
World code error: index.js:28 require must be a relative path ( / or ./ ): config.js
```

结论：**`require()` 的参数必须是 `./` 或 `/` 开头的静态相对路径字面量**。
裸文件名 `config.js` 会在打包期被直接拒绝；变量、函数包裹的 `require` 也建不出模块图。

`tsconfig.json` 里 `"module": "ESNext"` + `"moduleResolution": "bundler"` 印证了这是打包期静态解析。

官网教程（https://bloxd.io/docs/changelog.md，2026-08-18）同时规定：
- `index.js` 是唯一回调入口，**不能被其他文件 import**
- 官方推荐 `import`/`export`；`require()` technically works
- 总代码上限 512k 字符
- `console.log` 以 `Log:` 形式显示在**聊天框**（不是控制台）

## 二、本版改了什么

| 项 | 处理 |
|---|---|
| 40 处跨文件引用 | 全部统一为 `require("./xxx.js")` 单一静态字面量 |
| `index.js` 启动探针 | **整段删除**。原来把 require 包在 `() => require(...)` 箭头函数里，打包器静态扫描不到，且三路径候选里的裸名直接触发上面那条报错 |
| 诊断文件 | `诊断-自动定位.js`、`诊断-最小世界代码.js` 已从包内删除。它们含 `tick = () => {}` 回调赋值，且 `require('./index.js')` 违反"index.js 不能被 import" |
| 版本号 | `v2.6.6-20261114` |

`index.js` 开头现在是官网风格的顶层静态引用：

```js
console.log('[搜打撤] init 开始');
const config = require("./config.js");
const db = require("./db.js");
const menu = require("./menu.js");
const customweapons = require("./customweapons.js");
const game = require("./game.js");
const fittings = require("./fittings.js");
console.log('[搜打撤] init 模块加载完成, 代码版本 ' + (config.VERSION || '未知'));
```

## 五、若仍报 `require must be a relative path`

说明你贴的 `index.js` 还是旧版（第 28 行有裸名 `require("config.js")`）。
在编辑器里搜 `config.js`，确认所有出现都是 `require("./config.js")`，没有单独的 `require("config.js")`。

若报的是 `could not resolve ./config.js`，则是 Files 面板里缺该文件，按第四节清单逐个补齐。
