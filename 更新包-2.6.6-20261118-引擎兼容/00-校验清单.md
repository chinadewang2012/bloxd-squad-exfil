## 二、本次热修：为什么只改 2 个文件

### 🔴 实装反馈报错

```
Error in world code (internal): Object is not iterable (cannot read property Symbol.iterator)
```

### ✅ 根因

Bloxd 代码块引擎的 Set/Map 原型**没有 `Symbol.iterator`**。任何以下写法都会崩溃：

| 崩溃写法 | 影响位置 |
|---|---|
| `for (const [k, v] of map)` | `G.players` 全部遍历 ×6 处 |
| `for (const v of set)` | `markerMaps` / `SPAWNABLE_MOBS` / `mutedPlayers` |
| `[...set]` / `[...map.keys()]` | `getMutedList` / `[...team.members]` ×4 |
| `[...new Set(arr)]` 去重 | 撤离类型展示 / 违禁品名字去重 |
| `set.values().next().value` | `leaveTeam` 选新队长 |

### 🟢 修复方案

| 原写法 | 修复写法 |
|---|---|
| `for (const [k, v] of map)` | `map.forEach((v, k) => { ... })` |
| `[...set]` | `setToArray(set)` — helper 用 `set.forEach` |
| `[...map.keys()]` | `mapKeys(map)` — helper 用 `map.forEach` |
| `[...map.entries()]` | `mapEntries(map)` — helper 用 `map.forEach` |
| `[...new Set(arr)]` | `unique(arr)` — 用普通对象去重 |
| `set.values().next().value` | `setToArray(set)[0]` |

### 📊 变更统计

| 文件 | 字节变化 | 行数变化 | 新增 Helper |
|------|---------|---------|------------|
| game.js | +601 (98135→98736) | -86 (1997→1911) | `setToArray` `mapKeys` `mapEntries` `unique` |
| team.js | +376 (7504→7880) | -16 (211→195) | `setToArray` `mapKeys` |

> 行数减少是因为把嵌套 for 循环改成了 forEach + 提前 return，结构更扁平。

### 🔒 未改 11 个文件的验证

全库生产代码已零残留 Set/Map 迭代器用法（见 `grep '\[\.\.\.|for..of.*Map\|for..of.*Set'` 输出）。
数组的 `for...of` 和展开 `[a, ...arr]` Bloxd 引擎支持，本次未动。
