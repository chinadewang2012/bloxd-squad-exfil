## 一、为什么出这个包

实装报错：

```
Error in world code (internal): Object is not iterable (cannot read property Symbol.iterator)
```

**根因**：Bloxd 代码块引擎的 Set / Map **没有 Symbol.iterator**。
任何 `for...of` / `[...set]` / `[...map.keys()]` / `[...map.entries()]` / `[...new Set(arr)]` 都会崩溃。

**影响**：全库找到约 19 处迭代器用法，集中在 `game.js`（G.players/mutedPlayers/markerMaps/SPAWNABLE_MOBS）和 `team.js`（team.members/pendingInvites）。

**修复**：全部改成 Set/Map 原型方法 `.forEach()` + 4 个兼容 helper（见 `00-校验清单.md` 第二节）。

## 六、代码状态说明

本包仍是 CommonJS `require("./xxx.js")` 写法（Bloxd 代码块唯一支持的模块系统），
没有改成 ESM，没有三路径兼容层，没有诊断逻辑。

Set / Map / 迭代器的全面修复是**永久化**的 —— 以后加新功能也必须遵守：
- Set / Map 只用 `.forEach()` / `.has()` / `.get()` / `.set()` / `.delete()` / `.size` / `.add()`
- **禁止** `for...of`、展开 `[...set]`、`.keys()` / `.entries()` / `.values()` 返回的迭代器
- 去重用 `unique(arr)` helper，不用 `[...new Set(arr)]`
