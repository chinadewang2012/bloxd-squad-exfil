## 配置参数详解

### 全局配置
| 参数 | 类型 | 说明 |
|------|------|------|
| `title` | string | 系统标题，显示在右侧信息栏 |
| `jj` | array | 境界配置数组 [[战力,名称,颜色],...] |
| `zones` | object | 区域配置对象 {区域名: 区域配置, ...} |

### 区域配置
| 参数 | 类型 | 说明 |
|------|------|------|
| `name` | string | 区域显示名称 |
| `zone` | array | 检测区域 [xmin,xmax,ymin,ymax,zmin,zmax] |
| `rx` | array | 怪物X刷新范围 [min,max] |
| `ry` | array | 怪物Y刷新范围 [min,max] |
| `rz` | number | 怪物Z固定坐标 |
| `mob` | string | 怪物实体类型 |
| `mobName` | string | 怪物头顶显示名 |
| `max` | number | 区域最大怪物数量 |
| `count` | number | 每次刷怪数量 |
| `dropRate` | number | 丹药掉落概率 (0-1) |
| `dan` | array | 丹药配置数组 [{name,item,hp,atk},...] |

### 丹药配置
| 参数 | 类型 | 说明 |
|------|------|------|
| `name` | string | 丹药显示名 |
| `item` | string | 物品类型 |
| `hp` | number | 增加的生命值 |
| `atk` | number | 增加的攻击力 |
