# 测试版本D - 物品重量与摸金池版

## 版本信息
- **版本号**: vD.0
- **特色功能**: 7个摸金池（350+物品）+ 物品重量系统
- **加载顺序**: 世界代码 → 变量 → 外扩代码

## 文件说明

### 1. 物品重量与摸金池模块.js
**核心数据模块**，包含：
- **物品重量配置表** (`wupinzhongliang`): 200+物品的重量配置
  - 检测逻辑：通过 `api.getItemName` 获取物品命名进行匹配
  - 重量范围：0.0（屏障）~ 9.0（下界合金块）
  - 分类：基础资源、矿物、工具武器、防具、食物、建筑材料、红石、宝藏等

- **七个摸金池**（每个50个物品，共350个物品）：
  1. **普通摸金池** (`PutongChi`): 基础资源、原木、食物等
  2. **精良摸金池** (`JingliangChi`): 铁器、金器、基础装备
  3. **稀有摸金池** (`XiyouChi`): 钻石、红石、实用工具
  4. **史诗摸金池** (`ShishiChi`): 钻石装备、附魔书、特殊物品
  5. **传说摸金池** (`ChuanshuoChi`): 下界合金、鞘翅、信标
  6. **神话摸金池** (`ShenhuaChi`): 附魔装备、盔甲纹饰、稀有唱片
  7. **至尊摸金池** (`ZhizunChi`): 神级装备、命令方块、调试工具

### 2. 外部函数模块.js
**功能实现模块**，包含八大系统：
1. **撤离系统**: 撤离点检测、进度计算
2. **摸金系统**: 7个摸金池、冷却控制、掉落计算
3. **重量系统**: 背包重量计算、超重检测
4. **队伍系统**: 创建/加入/离开队伍、队伍聊天
5. **救援系统**: 倒地检测、救援机制
6. **成就系统**: 成就检查、奖励发放
7. **聊天系统**: 消息过滤、快捷发言
8. **错误处理**: 参数检查、异常捕获

### 3. 世界代码.js
**回调接口模块**，处理Bloxd.io官方回调：
- `onPlayerJoin`: 玩家加入初始化
- `onPlayerLeave`: 玩家离开清理
- `onPlayerDeath`: 死亡处理、KD统计
- `onPlayerAttemptOpenChest`: 摸金系统触发
- `onPlayerChat`: 聊天指令处理
- `onPlayerClick`: 点击事件
- `onPlayerMove`: 移动检测、撤离点检查
- `onPlayerDamage`: 受伤处理
- `onTick`: 游戏刻更新

## 摸金系统说明

### 触发方式
在箱子上方放置对应颜色的羊毛，打开箱子时触发摸金：

| 羊毛颜色 | 摸金池等级 | 物品品质 |
|----------|------------|----------|
| 白色 | 普通 | 基础资源 |
| 橙色 | 精良 | 铁/金装备 |
| 品红色 | 稀有 | 钻石/红石 |
| 淡蓝色 | 史诗 | 钻石装备 |
| 黄色 | 传说 | 下界合金/鞘翅 |
| 黄绿色 | 神话 | 附魔装备 |
| 粉红色 | 至尊 | 神级/命令方块 |

### 掉落机制
- 基础爆率 × KD值 × 全局爆率系数
- 每个摸金池最多掉落9种物品
- 冷却时间：5秒

## 重量系统说明

### 重量计算
- 检测物品命名（而非原名）
- 支持堆叠物品重量累加
- 默认最大负重：50

### 超重惩罚
- 超重时受到额外20%伤害
- 移动速度降低（可通过代码扩展）

## 加载顺序

```
1. 世界代码.js      → 加载回调函数框架
2. 物品重量与摸金池模块.js  → 加载数据配置
3. 外部函数模块.js  → 加载功能实现
```

## 注意事项

1. **激活顺序**: 必须先加载世界代码，再加载外扩代码
2. **回调限制**: 世界代码只能通过官方回调触发外扩代码
3. **变量共享**: 外扩代码中的全局变量可在世界代码中访问
4. **错误处理**: 使用 `typeof` 检查函数是否存在后再调用
