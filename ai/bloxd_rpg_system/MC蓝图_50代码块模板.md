# MC蓝图转Bloxd - 50代码块生成模板

## 使用步骤

1. **提取坐标**：使用 Amulet Editor 或 NBTExplorer 打开 `.litematic` 文件，导出方块坐标
2. **粘贴数据**：把你的坐标数据粘贴到下面的模板中
3. **分块生成**：最多分成50个代码块，逐个运行

---

## 代码块 1/50 - 基础设置

```javascript
// ========== 代码块 1: 基础设置 ==========
// 在这里粘贴你的方块数据
var blocks = [
    // 格式: [x, y, z, "方块名"]
    // 示例:
    // [0,0,0,"Stone"],
    // [1,0,0,"Stone"],
    // ...粘贴你的前一部分数据
];

// 批量放置函数
var placeBlocks = function(blockList){
    for(var i=0;i<blockList.length;i++){
        var b=blockList[i];
        if(b[3]!=="Air"){
            api.setBlock(b[0],b[1],b[2],b[3]);
        }
    }
};

// 放置第一批
placeBlocks(blocks);
api.broadcastMessage([{str:"[1/50] 代码块1完成",style:{color:"green"}}]);
```
