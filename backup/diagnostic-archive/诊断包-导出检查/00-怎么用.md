# 导出诊断（只换 1 个文件）

## 为什么做这个

新服报错：`TypeError: game.onTick is not a function`。
含义是：`require("./game.js")` **返回了对象，但里面没有 `onTick`** —— 不是模块加载失败，
而是 `game.js` 的 `module.exports = {...}` 没执行到，或文件内容不完整。

`game.js` 的导出块在**第 1985 行 / 共 1997 行**，是文件最末尾。
如果粘贴时被截断、或贴成了空文件/旧内容，就会出现这个现象。

（更正：官网 `64k → 512k` 指的是**总代码量**上限，我们是 297k 没超；
"单文件 64k 截断"只是猜测，本诊断就是为了把它证实或排除。）

## 操作步骤

1. 在**新服**（保持现在这 13 个文件不动）。
2. 只把 `index.js` 的内容**整文件替换**为本目录下的 `index.js`（约 30 行）。
   其余 12 个 `.js` 一个都不用动。
3. 确认编辑器提示**保存成功**，重进世界。
4. 聊天框会收到两条消息（`Log:` 里也有）：

```
[诊断] config=20 db=39 guns=3 mobs=5 customweapons=... game=...
[诊断] game.onTick 类型 = function | VERSION = v2.6.6-20261114
```

## 正常基线（本地实测，完整包 13 文件齐全时）

```
[诊断] config=20 db=47 guns=3 mobs=5 customweapons=8 maps=19 loot=33
       team=18 operators=14 fittings=26 menu=24 game=40
[诊断] game.onTick 类型 = function | VERSION = v2.6.6-20261114
```

**只要 `game=40` 且 `game.onTick=function`，就说明 game.js 是完整的。**
聊天里收到的数字可以直接和这行对照。

## 结果判读

| 现象 | 结论 / 下一步 |
|---|---|
| `game.onTick=function` 且 VERSION 正常 | 模块导出完好，问题在别处 → 把完整诊断消息发我 |
| **`game=` 后面的数字是 0 或很小** | `game.js` 内容不完整/被截断 → 重新整文件粘贴 `game.js`，重点确认编辑器里能看到文件末尾的 `module.exports = {` 那一整段 |
| `config=0` 或 `VERSION=空` | `config.js` 没贴对，重新贴 |
| 某个模块 `=-1` | 该模块导出异常，把消息发我 |
| 仍 `Save failed` | 编辑器问题，与代码无关 |

**最快的肉眼检查**：在编辑器里打开 `game.js`，直接跳到文件末尾，
应该能看到 `module.exports = { onTick, onJoin, ... G, };` 这一整段；
文件应为 **98135 字节 / 1997 行**（见 `更新包-2.6.6-全新/00-校验清单.md`）。
