# 修仙系统 - 玩家加入回调

```javascript
onPlayerJoin = function(pid, firstTime) {
    var st;
    try {
        st = gS(pid);
    } catch(e) {
        api.log('onPlayerJoin: gS error');
        return;
    }
    
    if (st.a <= 10 && st.h <= 10) {
        try {
            sS(pid, 10, 20, 0, 1, 0);
        } catch(e) {
            api.log('onPlayerJoin: sS error');
        }
        st = {a: 10, h: 20, r: 0, x: 1, j: 0, o: 0};
    }
    
    try { aS(pid); } catch(e) { api.log('onPlayerJoin: aS error'); }
    try { sA(pid); } catch(e) { api.log('onPlayerJoin: sA error'); }
    try { uSB(pid); } catch(e) { api.log('onPlayerJoin: uSB error'); }
    
    var rl;
    try {
        rl = gR(gP(st));
    } catch(e) {
        api.log('onPlayerJoin: gR/gP error');
        rl = {n: '未知', c: 'gray'};
    }
    
    api.sendMessage(pid, [
        {str: '[修仙]欢迎！境界:', style: {color: 'yellow'}},
        {str: rl.n, style: {color: rl.c}}
    ]);
};
```

## 优化说明

1. **添加变量声明**：明确声明 `st` 和 `rl` 变量
2. **错误处理增强**：每个 catch 添加具体错误信息，便于排查
3. **防御性编程**：gS 失败时直接返回，避免后续错误
4. **默认值处理**：rl 获取失败时使用默认值
5. **代码格式化**：统一缩进和换行，提高可读性
6. **消息数组分行**：长数组分行显示，更清晰

## 变量说明

| 变量 | 含义 |
|------|------|
| `st.a` | 攻击力/属性A |
| `st.h` | 生命值/属性H |
| `st.r` | 等级/境界 |
| `st.x` | 修为/经验 |
| `st.j` | 金币/货币 |
| `st.o` | 其他/特殊属性 |

## 函数说明

| 函数 | 作用 |
|------|------|
| `gS(pid)` | 获取玩家状态 |
| `sS(pid, ...)` | 设置玩家状态 |
| `aS(pid)` | 初始化属性 |
| `sA(pid)` | 更新属性 |
| `uSB(pid)` | 更新计分板 |
| `gP(st)` | 获取境界等级 |
| `gR(level)` | 获取境界信息 |
